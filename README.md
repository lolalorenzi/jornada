# 🧭 Jornada Viagens

Site de uma agência de viagens fictícia desenvolvido durante a formação de Front-end da [Alura](https://www.alura.com.br/). O projeto coloca em prática conceitos fundamentais de HTML e CSS na construção de uma landing page completa e responsiva.

## 📋 Sobre o Projeto

A **Jornada Viagens** é uma landing page para uma agência de turismo, com foco em apresentar destinos, pacotes e condições de pagamento de forma atraente ao usuário. O layout foi construído do zero com HTML semântico e CSS customizado.

---

## ✨ Funcionalidades

- **Header com menu responsivo** — navegação com checkbox hack para mobile
- **Seção Hero** — imagem de destaque com chamada da agência
- **Ofertas da Semana** — cards de destinos com preços (Japão, San Andreas, Paraíba, Manaus)
- **Busca por Categoria** — Pacotes Nacionais, Internacionais, Transfer e Seguro Viagem
- **Destinos Populares** — Tokyo e Osaka com descrições
- **Condições de Pagamento** — parcelamento em 12x, desconto no crédito e no Pix
- **Depoimentos** — avaliações de clientes com sistema de estrelas
- **Footer** — logo, horário de atendimento e links para redes sociais

## 📚 Aprendizados

Este projeto foi desenvolvido como parte da jornada de aprendizado em Front-end na Alura, cobrindo:

- Estruturação de páginas com HTML semântico (`<header>`, `<section>`, `<article>`, `<footer>`)
- Criação de layouts com CSS Flexbox e Grid
- Técnicas de responsividade mobile-first
- Uso de variáveis CSS e boas práticas de organização de estilos
- Acessibilidade com atributos `alt`, `title` e `lang`
